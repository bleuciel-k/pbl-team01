# Gesture Magic Battle ブラウザ版

バージョン v0.1 · 2026-11-24

リポジトリのルートで以下を実行し、Chromeで `http://127.0.0.1:8080` を開きます。ローカルで配信するにはNode.jsを使用します。

```sh
npx --yes http-server@14.1.1 web -a 127.0.0.1 -p 8080
```

1. **カメラを起動**を押して、ブラウザでカメラを許可します。初回はMediaPipeと手の追跡モデルの読み込みにインターネット接続が必要です。
2. 難易度を選び、**バトル開始**を押します。左上の見本を参考に、攻撃ターンは握りこぶし、防御ターンは開いた手を約0.3秒維持します。
3. ターンが変わったら、いったん手を緩めて次のポーズを作ります。認識結果は左のパネル、行動ログはバトル画面の下に表示されます。

チームで共有する場合は `web/` をHTTPSで配信します。カメラ映像はブラウザ内で処理します。図と機能要件は [要求仕様書](../docs/specs/requirements.md) を参照してください。この試作ではMPの数値を未設定として表示し、アイテム認識と効果音は今後の作業です。
