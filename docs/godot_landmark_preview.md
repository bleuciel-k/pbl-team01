# フェーズ2：Godotで手のランドマークを確認する

バージョン v0.1 · 2026-11-23

Pythonの追跡結果をローカルUDPで受信し、Godot 4で片手のランドマーク21点を表示します。両手を検出した場合は右手を優先します。

## 実行

1. Godot 4で `godot/project.godot` を開き、プロジェクトを実行します。
2. リポジトリのルートから、フェーズ1と同じ仮想環境とモデルを使って実行します。

   ```bash
   .venv/bin/python -m app.landmark_stream --model .venv/hand_landmarker.task
   ```

3. 片手をカメラに映し、Godotの点が手の動きに追従することを確認します。手を画面の外に出すと点が消え、戻すと再表示されます。

録画映像を使う場合は `--video path/to/video.mp4` を追加できます。Python側のウィンドウを開かない場合は `--headless` も指定します。

## UDPの形式

宛先は `127.0.0.1:5005` です。推論フレームごとに1つのJSONを送ります。

| フィールド | 内容 |
| --- | --- |
| `version` | 形式のバージョン。初版は `1`。 |
| `sequence` | 送信処理のフレーム番号。`0` から始まります。 |
| `timestamp_ms` | MediaPipeの動画モードに渡した単調増加の時刻。ミリ秒単位です。 |
| `hands` | 最大2件の検出結果。各要素の `side` は `Left` または `Right`、`landmarks` は21個の `[x, y, z]` です。手を検出できないフレームでは空配列になります。 |

`x` と `y` は反転していない入力画像上の正規化座標で、右・下が正方向です。`z` はMediaPipeが返す相対深度です。Godotの確認画面では、PythonのWebカメラ表示に合わせて描画時に `x` を反転します。受信側は順序の古いフレームを破棄し、有効な受信が500ミリ秒なければ点を消します。
