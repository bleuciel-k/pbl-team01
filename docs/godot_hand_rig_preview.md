# フェーズ2：3Dの右手モデルで追跡結果を確認する

バージョン v0.1 · 2026-11-23

Godotの `Skeleton3D` で手首と15個の指ボーンを動かします。手のモデルはGodotで生成する簡易モデルです。手首の位置は画面中央に固定され、手の向きと指の曲げ伸ばしが追跡結果に合わせて変化します。

## 実行手順

1. Godotで `godot/project.godot` を開き、実行中の2D確認画面を停止します。両方のシーンが同じUDPポート `5005` を使います。
2. ファイルシステムから `hand_rig_preview.tscn` を開き、**現在のシーンを実行**（`F6`）を選びます。
3. プロジェクトのルートディレクトリで既存のPython環境とモデルを使って送信を開始します。

   ```bash
   .venv/bin/python -m app.landmark_stream --model .venv/hand_landmarker.task
   ```

Pythonの送信プログラムがすでに動作している場合はそのまま使えます。右手を映すと3Dモデルが表示され、右手が検出されなくなるとモデルが消えます。

## 動作確認

- 右手を開き、5本の指が伸びることを確認します。
- 右手を握り、指が手のひらの方向に曲がることを確認します。
- 人差し指だけを伸ばし、他の指が曲がった状態で人差し指が伸びることを確認します。
- 手首をゆっくり回し、手のひらの向きが追従することを確認します。

指の長さと根元の位置はモデルに合わせて固定しています。手が重なってランドマークの推定が不安定になると、モデルの動きも乱れることがあります。
