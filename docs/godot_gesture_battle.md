# 両手の3D表示とジェスチャーバトル

バージョン v0.1 · 2026-11-23

## 起動

Godotで `godot/project.godot` を開き、実行中の確認画面を停止します。次のいずれかのシーンを開き、**現在のシーンを実行**（Macのキー設定によっては `Fn` + `F6`）を選びます。各シーンはローカルUDPポート `5005` を使用します。

| シーン | 確認内容 |
| --- | --- |
| `dual_hand_preview.tscn` | 左右の3Dモデルが独立して追従します。片手が画面外に出ると、その手のモデルだけが消えます。 |
| `gesture_battle.tscn` | 両手の3D表示と、ジェスチャーによる1対1のターン制バトルを試せます。 |

リポジトリのルートディレクトリで、既存の仮想環境からカメラの送信を開始します。送信がすでに動作している場合は、そのまま使えます。

```bash
.venv/bin/python -m app.landmark_stream --model .venv/hand_landmarker.task
```

## バトルの遊び方

1. 難易度を選び、`Start battle` を押します。
2. 攻撃ターンは5秒です。どちらか一方の手で握りこぶしを約0.3秒維持すると、火球で相手に20ダメージを与えます。
3. 相手が攻撃する3秒間に、手を開いて約0.3秒維持すると攻撃を回避します。時間切れの場合は、`Easy` で15、`Normal` で25ダメージを受けます。
4. 両者は100 HPで開始します。相手のHPが0になると勝利し、自分のHPが0になると敗北します。`Play again` で再開できます。

同じ姿勢を保持したままでは再発動しません。該当するターンに入ってから一度手を緩め、もう一度ポーズを作ります。親指以外の4本の指の形で握りこぶしと開いた手を判定します。
